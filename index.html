Sunprime Redesign

Este projeto é um site Next.js para o estúdio Sunprime, com foco em empreendimentos imobiliários de alto padrão e experiência visual em Itapema, SC.

O aplicativo usa:

  • Next.js 14
  • React 18
  • Tailwind CSS
  • Sanity para CMS
  • Three.js e framer-motion para animações

Principais rotas:

  • / - página principal
  • /empreendimentos - lista de projetos
  • /sobre - manifesto e informações da empresa
  • /contato - formulário ou informações de contato

Como rodar localmente:

  • Instalar dependências: npm install
  • Executar em desenvolvimento: npm run dev
  • Build de produção: npm run build
  • Iniciar produção: npm start

Arquivo gerado automaticamente para facilitar a visualização do projeto no diretório raiz.
